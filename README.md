# TraceChain
1. Deploy `contract/TraceChain.sol` on BOT Chain. The deployer becomes admin.
2. Set `CONTRACT_ADDRESS` in `js/app.js`.
3. Serve the folder (e.g. VS Code Live Server) and open `index.html`.
Roles: Admin registers participants; participants register products, log updates, transfer custody and mark delivery; anyone can track by ID (no wallet).
Not audited; test on a testnet first.
